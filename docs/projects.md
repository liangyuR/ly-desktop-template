# 项目文件与迁移

应用资料根目录下的 `projects/<uuid>/project.json` 保存项目编号、名称、描述与格式版本。业务模块将需要随项目复制和导出的配置、资源放入同级 `portable/<模块名>/`，把本机凭据、绝对路径、运行记录和缓存放在其他位置。包内复制文件内容，不保存空目录；需要的目录由模块打开时创建。

`projects/current.json` 保存上次选择的项目编号。启动时按目录读取项目清单，仅重新打开仍然可读的项目。切换时先打开目标项目，再更新本机选择。后台操作应在启动时取得自己的项目编号，后续读写使用该编号。

导出的 `.lyproj` 是 ZIP。版本 1 的 `manifest.json` 记录格式标识、版本、项目名称和描述、UTC 导出时间（Unix 秒），以及每个 `portable/` 文件的字节数和 SHA-256。校验值用于发现损坏，不提供发行者身份认证。导入先在独立暂存目录校验内容和路径，再分配独立的项目身份并加入列表。重复导入同一包可得到同名但编号不同的两个项目。模板支持最多 16,384 个资源文件和 8 GiB 解压资源，每个清单最多 8 MiB。

创建、复制、导入均保留当前项目，只有列表从空变为非空时会自动打开首个项目。删除当前项目后进入未选择状态。
